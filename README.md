# 📚 Personal Library Manager

A **command-line library manager** in Python that stores your book collection in a JSON file so it persists between runs.

## Features

- Add, view, and manage books
- **Persistent storage** via a `library.json` file
- Graceful handling of a missing/empty data file
- Class-based (`PersonalLibrary`) design

## Run it

```bash
python "Personal Library Manager.py.py"
```
